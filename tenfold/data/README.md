# data/

Data from the 1885 sources. Everything here was either transcribed by Claude (reading the page
images) or generated by a script in `scripts/` from such a transcription. Transcriptions cannot be
regenerated by a script; they can be checked against the sources, and are checked automatically
where possible.

## census_p503.txt (transcribed by Claude)

Tait's list of all 364 forms of the 123 tenfold types, *On Knots. Part III*, §21, p. 503
(`sources/s0080456800025242.pdf`). One line per type: `<type>: <code> <code> …` in plate order.
A trailing `*` marks an amphicheiral, printed as a single barred letter (C̄ → `C*`).

Greek letters were transcribed from the page image, not the PDF text layer (which garbles them).
Ambiguous letters were resolved by the rule that a 5/7 code pairs one Latin and one Greek letter
(e.g. OCR "ee" → `εe`, "re" → `rε`, "a/3" → `aβ`).

## census.csv (generated by `scripts/build_census.py`, extended by `../scripts/trace_rows.py` and by Claude)

UTF-8, one row per form. Regenerating keeps whatever is already in `row`, `col`, `kirkman`, `notes`.

The `kirkman` column was **transcribed by Claude**, like `census_p503.txt`: read off the label
contact sheets made by `scripts/extract_kirkman.py` (each label cropped from all three scans).
Misprints are corrected (see below and the [errors table](../README.md#errors-and-inconsistencies-in-the-1885-publications)); the printed value is kept in `notes`. It cannot be regenerated by a script
(tesseract OCR of the small superscripts was too unreliable); what is reproducible is checking it:
regenerate the contact sheets and compare by eye, and run the two independent checks:

- the numbers per letter form a sequence 1…n — except C, which runs to C⁸⁰ without C⁵² (see the
  [errors table](../README.md#errors-and-inconsistencies-in-the-1885-publications));
- `scripts/check_kirkman.py`: the letter must match the knot's flaps as defined by Kirkman's lists
  (`sources/s0080456800025230.pdf`). With the corrections below, all 363 match.

Corrections (printed value kept in `notes`): #70 C⁵² → D⁴⁷ (its flaps put it in list D); #32 C¹³ →
C¹¹ (C¹³ is printed twice, C¹¹ never; the second occurrence is renamed by convention). The region
code of #352 is corrected from `lκ` to `κl` in `scripts/build_census.py` (`CODE_CORRECTIONS`).

| column | meaning |
|---|---|
| `seq` | position in Tait's list (1–364) = reading order on the plates |
| `type` | Tait's type number (1–123) |
| `form` | index of this form within its type |
| `code` | Tait's two region letters as printed (`*` = barred = amphicheiral) |
| `family` | mesh split `6/6`, `5/7`, `4/8` or `3/9`; selects the letter → partition table (§18, p. 501; see `tait/codes.py`) |
| `plate` | `LXXX` (seq 1–182) or `LXXXI` (seq 183–364; type 46 straddles the two plates) |
| `row`, `col` | position on the plate (filled by `../scripts/trace_rows.py`) |
| `kirkman` | Kirkman's designation printed top-right of each figure, e.g. `B28` = B²⁸ (letter + superscript number; Greek capitals Δ Θ Ξ Σ Φ at the end of LXXXI). Empty for #133, where none is printed |
| `notes` | remarks on individual forms (discrepancies, uncertain readings) |

What a code means: each letter is a partition of 20, the corner counts of one class of meshes
(regions) in the checkerboard colouring of the diagram. The **second** letter is the class that
contains the outer region (§21, p. 502). Both facts are checked for every traced knot.

Notes:
- The same Latin letter means different partitions in different families
  (`a` = 77222 in 5/7 but 8732 in 4/8).
- Type 79: the order of its two forms on the plate is the reverse of the p. 503 list.
  `census.csv` follows the plate (see `PLATE_ORDER` in `scripts/build_census.py`).
- Form 352 (type 111): printed `lκ` (text and plate), but its outer region is in class l, and by Tait's
  convention the second letter is the class of the outer region. The letters themselves are right
  (confirmed by tracing), only their order is not: `census.csv` has the corrected `κl`
  (`CODE_CORRECTIONS` in `scripts/build_census.py`) and records the printed code in `notes`.
- Type 109: Tait's late correction (pp. 505–506) merges the two forms printed under 109 into one
  type, giving 123 types.
- `build_census.py` checks the transcription against Tait's own totals:
  133 / 200 / 25 / 6 forms in the four families, 364 forms in 123 types.
