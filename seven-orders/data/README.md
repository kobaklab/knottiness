# data/

Data from the 1884 paper and plate. Transcriptions were made by Claude reading the page images; they
cannot be regenerated by a script, but are checked automatically where possible.

## plate_xliv.txt (transcribed by Claude)

Every figure of Plate XLIV in plate (reading) order, one line per type: its order (crossing number),
its numeral as printed, the group header as printed ("III Two forms", "I Un. Amphichˡ", …), and for each
form Kirkman's designation (`9 Bg` → `Bg`) and, for the 6- and 7-folds, the designation from Tait's
former paper (`β 6A`, `II, 7C`). Format in the file's header.

## partitions_p332.txt (transcribed by Claude)

Tait's §6 (pp. 332–334): for each figure, the corner counts of the meshes (regions) of the two classes
of the checkerboard colouring, as printed: upper/lower; a barred single partition (`332*`) means both
classes alike and the knot amphicheiral. The order of the two rows follows no rule visible on the
plate: the class containing the outer region is the upper one for 91 figures and the lower one for 44
(the rest: amphicheiral or both alike).

## census.csv (generated by `scripts/build_census.py`; row, col filled by `../scripts/trace_rows.py`)

| column | meaning |
|---|---|
| `seq` | position on the plate in reading order (1–144) |
| `order` | crossing number, 3–9 |
| `type` | type number within the order (Tait's Roman numeral for 7–9; position for 3–6) |
| `numeral` | the numeral as printed (empty for the 3- to 6-folds) |
| `form`, `n_forms` | index of this form within its type; number of forms |
| `kirkman` | Kirkman's designation, as printed after the order digit |
| `former` | designation from Tait's former paper (6- and 7-folds only) |
| `partitions` | Tait's partition pair (§6), `upper/lower`, or `p*` for a barred one |
| `amph` | 1 for the barred (amphicheiral) forms |
| `header` | the group header printed above the first form of the type |
| `plate`, `row`, `col` | `XLIV`; position on the plate |
| `notes` | remarks |

`build_census.py` checks: the header's number of forms ("Unique", "Two forms", …) = figures = partition
pairs in the text; barred partitions exactly where the header says "Amphich." (8 V: its 2nd and 3rd forms);
every partition sums to 2n with no part < 2 or > n, and each pair has n + 2 meshes; Kirkman's
designations unique within an order; Tait's totals (§5): 1, 1, 2, 3, 7, 18, 41 knots of 3–9 crossings,
144 figures. All pass. Every traced figure then matches its pair (`../scripts/trace_rows.py`).

## glyphs.yaml (hand-made)

with the options of `../tenfold/data/glyphs.yaml` (`instance`, `level`, `smooth`, `cuts`, `speck`, `edit:`).
